# Mosaic Privacy

Mosaic is built around files already on the device. Privacy is a design constraint, not a feature.

- No account is required.
- No advertising or analytics SDK is included.
- File, photo, and video content is never uploaded to a Mosaic service — there isn't one.
- Organizing and indexing run on-device, using on-device machine learning APIs only.
- Media and files remain at the locations the user selects; Mosaic does not maintain a private shadow copy.

Sharing a file or using an external storage provider (Files, iCloud Drive, etc.) sends data only through the service the user explicitly chooses, subject to that service's own privacy terms.
